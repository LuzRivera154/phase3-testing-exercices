# 🧪 Exercices PHPUnit avec Symfony

> Un projet d'apprentissage pour maîtriser les tests unitaires avec PHPUnit dans un environnement Symfony.

> 🍴 **Ce dépôt est un fork** du dépôt original créé par **[Massi Chaouchi](https://github.com/CHAOUCHI)**, formateur du cursus **CDPI** à **La Plateforme**.

## 📖 À propos

Ce dépôt contient une série d'exercices pratiques conçus pour apprendre à écrire des **tests unitaires** avec **PHPUnit** dans un projet **Symfony**. Chaque exercice cible une compétence spécifique du testing, du plus simple au plus avancé.

## 🎯 Objectifs pédagogiques

À travers ces exercices, vous apprendrez à :

- ✅ Écrire des tests unitaires clairs et efficaces
- 🧩 Utiliser les principales assertions de PHPUnit (`assertEquals`, `assertTrue`, `assertArrayHasKey`, etc.)
- 🚨 Tester la levée d'exceptions avec `expectException`
- 💉 Injecter des services Symfony dans vos tests via le container
- 📅 Gérer les valeurs dynamiques (dates, IDs générés) dans vos assertions
- 🎯 Atteindre un bon taux de couverture de code
